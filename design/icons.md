## 제외 목록

비슷해서 헷갈리는 아이콘. 쓰지 않는다.

| 쓰지 않음 | 이유 |
|---|---|
| arrow-left | 뒤로는 chevron-left 하나만 |
| x-circle | 닫기·불가능은 x 하나만 |
| more-horizontal | 더보기는 ellipsis-vertical 하나만 |
| calendar, calendar-check | 탭 홈은 calendar-days, 후보는 calendar-plus 하나씩만 |
| user-plus | 지인 추가도 plus 하나로 통일 |
| alert-circle, alert-triangle | 오류는 circle-alert, 겹침은 triangle-alert (lucide 신규 이름) |
| check-circle | 확정은 check-circle-2 하나만 |
| send | 공유·전송은 share-2 하나만 |
